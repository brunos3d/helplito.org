# Q-003: ION717 Regimen 3 recruitment

Is Regimen 3 closed to new enrollment everywhere, or does any institution remain
open under a local state not reconciled with ClinicalTrials.gov version 30?

## Current evidence

- Current overall registry state: `Active, not recruiting`.
- Current location states: absent.
- Current registry prose: sites actively recruit for open-label Regimen 3.
- Current Ionis pipeline label: `Active, not recruiting`.
- Current NYU page label: `Open`, with no visible update date.

## Falsification attempt

The `Open` hypothesis was checked against the newest registry version, sponsor
pipeline and CTIS. All provide evidence against ongoing recruitment, except for
the unchanged registry prose. The `Closed everywhere` hypothesis was checked
against NYU, which still provides contrary official evidence.

## What would resolve this question

A dated sponsor clarification, corrected ClinicalTrials.gov description or
dated institutional update explaining whether any Regimen 3 enrollment remains
open.

## Interpretation limits

This question does not establish immediate capacity, eligibility or access even
if one local page is later confirmed open.
