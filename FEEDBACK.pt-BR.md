# Feedback

[English](FEEDBACK.md)

Esta página é para quem usou o helplito.org e quer relatar um problema ou sugerir algo. Você não precisa saber como o site é construído.

Se você é o Lito, alguém da família, da equipe ou de uma instituição mencionada no site, use [CLAIMS.pt-BR.md](CLAIMS.pt-BR.md). Se quiser alterar o código por conta própria, veja [CONTRIBUTING.pt-BR.md](CONTRIBUTING.pt-BR.md).

## Dois endereços, dois propósitos

Feedback sobre o site vai para helplito@brunosilva.io ou para uma issue no GitHub neste repositório.

Informação científica, clínica ou institucional que possa ajudar o Lito vai para a equipe oficial em ajudalito@avioesemusicas.com, de preferência pelo formulário do site, que estrutura a mensagem para eles. O Help Lito não lê essa caixa de e-mail, então qualquer coisa enviada ao GitHub ou ao endereço da iniciativa sobre tratamentos ou ensaios clínicos só será encaminhada com atraso, se for.

Por favor, não envie sugestões de tratamentos não verificados para nenhum endereço.

## O que é útil relatar

- Uma página que não carrega ou mostra erro.
- Texto que transborda, sobrepõe ou fica cortado na sua tela. Diga qual dispositivo e navegador você usou.
- Um link que vai para o lugar errado ou está quebrado.
- Uma tradução errada, estranha ou inconsistente em qualquer idioma.
- Um problema com leitor de tela, teclado ou contraste.
- Algo que ficou confuso, ou informação que você procurou e não encontrou.
- Uma afirmação médica ou científica que você acredita estar imprecisa ou desatualizada. Inclua a fonte.
- Um ensaio clínico cujo status no site não bate mais com o registro oficial.
- Uma organização ou grupo de pesquisa em doenças priônicas que está faltando. Inclua o site oficial.

## Como relatar

### Por e-mail

Escreva para helplito@brunosilva.io. Um problema por mensagem é mais fácil de tratar, mas vários também serve. Capturas de tela ajudam. Informe o endereço da página, o dispositivo, o navegador e o idioma.

### No GitHub

Abra uma issue em https://github.com/brunos3d/helplito.org/issues e escolha o template que se encaixa: relato de bug, correção de conteúdo ou tradução, ou feedback geral. Issues são públicas; não inclua informações pessoais suas ou de outras pessoas. Os templates estão em inglês, mas você pode preencher em português.

## O que esperar

Toda mensagem é lida pela pessoa que mantém o site. Bugs que quebram uma página ou bloqueiam o formulário de contato são corrigidos primeiro. Correções de tradução e de texto costumam ser rápidas. Correções de conteúdo demoram mais, porque a fonte é conferida antes de qualquer mudança.

Este é um projeto voluntário com uma pessoa por trás, então respostas podem levar alguns dias. Se você relatou algo por issue, vai ver a correção chegar como um commit que a referencia.

Não adicionamos recursos que arrecadem dinheiro, rastreiem visitantes ou publiquem conteúdo enviado por usuários, então pedidos nesse sentido serão recusados com uma explicação curta.
